## Janvlog

Данный репозиторий является результатом дипломной работы на тему "Программа для протоколирвоания аудио/видео конференций на основе WebRTC".

В данном репозитории реализовано приложение, которое подключается к Janus серверу и протоколирует все встречи которые происходят в нем.

Для удобства тестирования и разработки был создан простой фронтенд на основе примера из оффициального репозитория [janus-gateway](https://github.com/meetecho/janus-gateway)

### Запуск сервера speech-to-text

Для запуска приложения необходимо установить зависимости:

```bash
pip install -r requirements.txt
```

Затем запустить приложение:

```bash
python cmd/whisper/server.py
```

### Запуск основного приложения:

```bash
go run cmd/janvlog/main.go
```

Так же нужно будет поправить файлы конфигурации для указания своего Janus-сервера и своей почты для отправки сообщений
